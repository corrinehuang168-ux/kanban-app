# UX & Accessibility Check Workflow (用戶體驗與 UI 檢查流程)

本 Workflow 用於對 Focus & Do (Kanban App) 進行全面性的 UI/UX 與使用者體驗稽核，確保介面視覺、互動回饋、無障礙與響應式體驗皆達到最高品質。

---

## 🎯 檢查階段與清單 (UX Checklist)

### 1. 視覺與主題體驗 (Visual & Theme Check)
- [ ] **深淺模式切換**：點擊右上方主題切換按鈕，確認所有卡片、背景、文字與 Icon 皆平滑過渡，沒有漏掉的主題顏色。
- [ ] **色彩對比度**：確保文字與背景對比度符合 WCAG AA 標準，在明亮模式與暗色模式下皆清晰易讀。
- [ ] **毛玻璃與 Ambient Glow 特效**：背景微光 (`.glow`) 與容器 blur 特效在桌面端與行動端均流暢呈現。

### 2. 任務建立與輸入體驗 (Task Creation UX)
- [ ] **必填與選填邏輯**：
  - 輸入空白標題提交時，表單自動阻擋 (`required`)，不會建立空任務。
  - 分類 (工作/生活)、優先級 (高/中/低)、負責人 (選填)、截止日 (選填) 皆能正常作用。
- [ ] **表單自動重置與 Focus**：新增成功後，標題、負責人、截止日自動清空，且焦點 (Focus) 自動回到標題輸入框。
- [ ] **預設選擇**：分類預設選中「💼 工作」，優先級預設選中「⚡ 中」，符合多數使用情境。

### 3. 截止日期與警示標籤 (Due Date & Alert Badges)
- [ ] **未到期日期**：選擇未來日期，卡片呈現正常的 `📅 YYYY/MM/DD` 灰色標籤。
- [ ] **今日到期 / 已過期日期**：選擇今日或過去日期，標籤自動呈現**醒目紅色背景與紅字** (`.overdue`)。
- [ ] **未填寫日期**：未選擇日期時，卡片不顯示日期標籤，維持版面乾淨。

### 4. 拖曳與看板互動 (Kanban Drag & Drop)
- [ ] **拖曳回饋 (Feedback)**：
  - 抓取任務卡片時，卡片呈現半透明 (`opacity: 0.4`) 與微幅縮放。
  - 拖曳至欄位上方時，目標欄位外框呈現鮮豔高亮 (`.drag-over`) 與擴張陰影。
- [ ] **狀態更新與持久化**：放開卡片後，任務成功移動至新欄位 (To-do / Process / Done)，重新整理頁面後狀態保持不變。
- [ ] **計數器實時更新**：看板欄位頂部標籤 (`todo-count`, `process-count`, `done-count`) 與頁尾未完成數量隨時正確更新。

### 5. 篩選與狀態切換 (Filters & Tab Navigation)
- [ ] **類別篩選 (All / Work / Life)**：點擊分頁標籤，僅顯示對應類別之任務，且 Active 標籤視覺高亮。
- [ ] **狀態篩選 (All / Active / Completed)**：狀態篩選切換順暢，且與類別篩選可疊加發揮作用。
- [ ] **空狀態 (Empty State)**：當無相符任務時，顯示優雅的「✨ 尚無待辦事項」提示圖示與說明。

### 6. 響應式與跨裝置體驗 (Responsive & Mobile Check)
- [ ] **平板 Viewport (< 768px)**：看板三欄自動彈性轉為直向堆疊，欄位之間保留足夠間距。
- [ ] **手機 Viewport (< 480px)**：表單選項垂直堆疊，按鈕與選擇器具備足夠的觸控點擊面積 (Tap Targets >= 44px)。

---

## 🛠️ 執行檢查與驗證步驟 (Verification Steps)

1. **開啟測試環境**：
   在瀏覽器開啟 [Live Site](https://corrinehuang168-ux.github.io/kanban-app/) 或本地 `index.html`。
2. **模擬典型使用者流程**：
   - 建立 1 個今日到期的高優先級工作任務。
   - 建立 1 個未來到期的低優先級生活任務。
   - 將任務從 To-do 拖曳至 Process 再拖至 Done。
   - 切換至暗色模式檢查文字與標籤顏色。
   - 重新整理網頁，驗證 LocalStorage 狀態恢復。
