# WebApp Testing Skill (前端應用測試與驗收規範)

本 Skill 提供完整且可自動執行的 Web 應用 QA 與 UI/UX 測試標準。

---

## 測試檢驗範疇 (Testing Checklist)

1. **功能驗證 (Functional Testing)**
   - 表單新增、欄位驗證（必填與選填處理）。
   - 排序、篩選與狀態切換邏輯。
   - LocalStorage 持久化儲存與重載回復。

2. **UI/UX 互動驗證**
   - Drag & Drop 拖曳回饋（高亮、半透明與視覺縮放）。
   - 空白狀態 (Empty State) 提示呈現。
   - 深淺模式過渡動畫與彩度比對。

3. **自動化 Workflow 執行**
   - 透過 `@workflow.md` 自動化逐項稽核與產出評估報告。
